# Functionality

This is recreation of the classic Block Breaker game where the ball bounces around the stage and is hit with a paddle, breaking the colored bricks it comes into contact with. Initially, the level is set where the blue bricks at the bottom require one hit to disappear. The green bricks above the blue bricks require two hits to disappear, and so on.
