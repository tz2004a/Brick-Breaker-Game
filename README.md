# Functionality

This is recreation of the classic Block Breaker game where the ball is hit with a paddle and bounces around the stage, breaking the colored bricks it comes into contact with. Initially, the level is set where the blue bricks at the bottom require one hit to disappear. The green bricks above the blue bricks require two hits to disappear, and so on.
